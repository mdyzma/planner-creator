# Logo concepts

Early logo proposals, kept for reference. The final artwork is in the folder above
(`../yapco-logo.svg`, `../yapco-mark.svg`, `../yapco-icon.svg`).

| File | Concept | Notes |
| --- | --- | --- |
| `concept-1-planner-apple.jpg` | Apple-shaped planner with binder rings and a checklist | Chosen as the base: the planner parts carry the meaning. Leaf moved onto a stem. |
| `concept-2-line-apple.jpg` | Line-art apple with a tick | Clean, but a generic apple icon; not recognisable as a planner. |
| `concept-2-line-apple.svg` | The same apple redrawn as a vector | Traced from the JPEG; sharp at any print size. The planner's title page uses a crop of the JPEG (`templates/therapeutic-recovery/assets/cover-apple.png`). |
| `concept-3-outline-wordmark.jpg` | Outline apple with a floating leaf and wordmark | Dropped: floating leaf and the notch read too close to Apple Inc.'s logo. |
| `yapco-image.jpeg` | Solid apple with a tick | |
| `yapco-image-with-title.jpeg` | The same with the "YAPCO." wordmark and tagline | Used as the logo in the repository README. |
