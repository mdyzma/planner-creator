# YAPCO brand

YAPCO — *Yet Another Planner Creator*. The mark is an apple-shaped planner: binder rings, a stem
with an attached leaf and a ticked checklist. The apple comes from the orchard region the project
is made in.

| File | Use |
| --- | --- |
| `yapco-logo.svg` | Mark with wordmark and tagline (README, about pages) |
| `yapco-mark.svg` | Full mark, 48 px and up |
| `yapco-icon.svg` | Simplified mark for 16–32 px (browser tab, app icon); same file as `apps/web/app/icon.svg` |

Colours: ink `#1e2424` (dark theme `#e6e2da`), tick `#c8322b`, leaf `#4a8a3c`.

Keep it clear of Apple Inc.'s logo: the leaf always sits on the stem, and the outline never has a
bite or a gap. The planner parts (rings, checklist) carry the meaning; the apple is secondary. In
the app header the name is shown as "YAPCO" alone; the tagline is for the README and about pages.
