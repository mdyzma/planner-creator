# XIII. Najważniejsza zasada UX

Nie wolno pokazać wszystkich tych pól naraz.

**Wersja papierowa:** użytkownik wybiera wariant przed wygenerowaniem PDF.

**Web app:** sekcje mają `enabled`, `required`, `compact`, `expanded`.

Przykładowo użytkownik wybiera:

> Daily Core  
> + Recovery  
> + Sleep  
> + CBT Lite

i dostaje swój planer.

Inny wybiera:

> Daily Core  
> + Productivity  
> + Wellbeing

i nadal dostaje **Dzień po Dniu**, ale jest to zupełnie inny planer.

To moim zdaniem jest właściwy kierunek całego produktu: **„Dzień po Dniu” nie powinien być jednym plannerem. Powinien być systemem do budowania własnego planera.**

A **Recovery Edition** jest po prostu jedną z gotowych konfiguracji tego systemu.
